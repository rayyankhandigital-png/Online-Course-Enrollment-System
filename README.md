# Online Course Enrollment System

## 📌 Project Description

The **Online Course Enrollment System** is a simple desktop application developed using **Python and Tkinter**. It allows students to select courses and enroll in them through an easy-to-use graphical interface.

The system uses **Tkinter** to create the user interface and **MessageBox** to display confirmation, success, and error messages.

## ✨ Features

* View available courses
* Enter student information
* Select a course
* Enroll in a course
* Display enrollment confirmation
* Show error messages for invalid input
* Simple and user-friendly interface

## 🛠️ Technologies Used

* **Python**
* **Tkinter** – Used to create the graphical user interface
* **MessageBox** – Used to display alerts, confirmations, and notifications

## ⚙️ How It Works

1. The user opens the Online Course Enrollment System.
2. The user enters their required information.
3. The user selects an available course.
4. The user clicks the **Enroll** button.
5. The system checks the entered information.
6. A **MessageBox** displays a success or error message.
7. If the enrollment is successful, the student receives a confirmation message.

## ▶️ How to Run

1. Make sure **Python** is installed on your computer.
2. Download or clone this project.
3. Open the project folder.
4. Run the following command:

```bash
python main.py
```

Tkinter is normally included with Python, so no additional installation is required.

## 🎯 Purpose

The purpose of this project is to demonstrate how **Python Tkinter** can be used to create a basic graphical application and how **MessageBox** can be used to communicate important information to the user.
