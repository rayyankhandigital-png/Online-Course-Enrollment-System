# Online Course Enrollment System

## 📌 Project Description

The **Online Course Enrollment System** is a simple Python desktop application built using **Tkinter**. It allows students to view available courses, enter their information, and enroll in a selected course.

The system uses **MessageBox** to display confirmation and error messages, while **JSON** is used to store enrollment data. The **OS** library is used to manage files and folders required by the application.

## ✨ Features

* View available courses
* Enter student information
* Select and enroll in a course
* Store enrollment information
* Display success and error messages
* Simple and user-friendly interface

## 🛠️ Technologies and Libraries Used

* **Python** – Main programming language
* **Tkinter** – Used to create the graphical user interface
* **MessageBox** – Used to display alerts, confirmations, and notifications
* **JSON** – Used to store and manage enrollment data
* **OS** – Used for file and directory management

## ⚙️ How It Works

1. The user opens the Online Course Enrollment System.
2. The user enters their required information.
3. The user selects a course.
4. The user clicks the **Enroll** button.
5. The system saves the enrollment information in a **JSON file**.
6. A **MessageBox** displays a confirmation message.
7. The **OS** library helps the program manage the required files and folders.

## ▶️ How to Run

1. Make sure **Python** is installed.
2. Open the project folder.
3. Run:

```bash
python main.py
```

Tkinter, JSON, and OS are part of Python's standard library, so they normally do not require separate installation.

## 🎯 Purpose

The purpose of this project is to demonstrate how **Python, Tkinter, MessageBox, JSON, and OS** can be combined to create a simple and functional course enrollment application.
